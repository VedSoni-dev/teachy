## Layout
- Left sidebar: the workspace name at the top (click it for workspace settings and switching), then Inbox, My issues, and your teams. Each team expands into Issues, Cycles, Projects and Views.
- The middle is the list or board of issues. Display options (list or board, grouping, ordering) are behind the Display button at the top right of the list.
- Opening an issue shows it full width or as a side panel: title and description on the left, properties (status, priority, assignee, labels, project, cycle, estimate) on the right.

## Where things are
- New issue: C, or the pencil button next to the workspace name.
- Search everything: Cmd+K opens the command menu; type an issue ID like ENG-123 to jump straight to it.
- Filter the list: F, or the Filter button above the list.
- Change an issue's status, assignee or priority: open it and use the right side, or select it in the list and press S (status), A (assignee), P (priority), L (labels).
- Link a pull request: put the issue ID in the branch name or PR title; the copy-branch-name shortcut is Cmd+Shift+. on an open issue.
- Notifications: Inbox at the top of the sidebar.
- Team settings, workflow states and templates: the team's name in the sidebar > Settings.

## Gotchas
- Almost every action has a single-key shortcut, so typing while an issue is selected but no text field is focused changes the issue. Click into the field first.
- Archived issues don't show in lists by default; search finds them.
- Statuses are per team. An issue moved to another team gets that team's statuses.

## Shortcuts
- Command menu: Cmd+K. New issue: C. Search: /.
- Go to inbox: G then I. My issues: G then M.
- Assign to me: I. Set status: S. Priority: P.
