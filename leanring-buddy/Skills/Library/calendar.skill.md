## Layout
- Toolbar: the Calendars button (shows or hides the calendar list), the Inbox for invitations, Add (+), the Day, Week, Month, Year switch in the middle, then Today with arrows, and Search.
- The calendar list groups calendars by account (iCloud, Google, Exchange, Other). Each has a checkbox that shows or hides its events. A mini month sits under the list.
- All-day events sit in a strip at the top of Day and Week views.

## Where things are
- New event: double-click an empty slot, or click + and type something like "Lunch Friday 1pm".
- Edit an event: double-click it. Time, repeat, alert, invitees, location, notes and the calendar colour square are all in that popover.
- Invite people: open the event > Add Invitees.
- Move an event to another calendar: Control-click it > Calendar.
- New calendar: File > New Calendar. Subscribe to a public one: File > New Calendar Subscription.
- Add a Google or Exchange account: Calendar > Add Account.
- Default calendar, week start, day start and end: Calendar > Settings > General.
- Time zone support: Calendar > Settings > Advanced.
- Default alert times: Calendar > Settings > Alerts.
- Share an iCloud calendar: Control-click it in the list > Share Calendar.
- Refresh: View > Refresh Calendars.

## Gotchas
- An event that "vanished" is usually in a calendar whose checkbox is off.
- Changing a repeating event asks whether to change only this event or all future ones.
- New events go to the default calendar unless a calendar is selected in the list. Check the colour before saving.
- Subscribed calendars are read-only.
- With time zone support on, a time zone menu appears next to Search and events are drawn in that zone.

## Shortcuts
- New event: Cmd+N. Delete: select and press Delete.
- Today: Cmd+T. Go to a date: Shift+Cmd+T.
- Views: Cmd+1 Day, Cmd+2 Week, Cmd+3 Month, Cmd+4 Year.
- Next and previous period: Cmd+Right Arrow and Cmd+Left Arrow.
- Edit the selected event: Cmd+E. Refresh: Cmd+R.
