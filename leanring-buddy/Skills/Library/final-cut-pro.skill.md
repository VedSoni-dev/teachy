## Layout
- Top left: the sidebar (Libraries, Photos and Audio, Titles and Generators) and next to it the Browser, which shows the clips in the selected event.
- Top middle: the Viewer. Top right: the Inspector, which shows settings for whatever is selected.
- Bottom: the Timeline. The main row is the primary storyline; clips above or below it are connected clips.
- A thin bar between the top and the timeline holds, from the left: the Timeline Index button, the four edit buttons (connect, insert, append, overwrite), the Tools menu (Select, Trim, Position, Range, Blade, Zoom, Hand), and at the right skimming, snapping, the Effects browser and the Transitions browser.
- Top right of the window: buttons to show or hide the Browser, Timeline and Inspector, and the Share button.
- Media is organised as Library > Event > Project. A project is one timeline.

## Where things are
- Import media: File > Import > Media.
- New project (timeline): File > New > Project.
- Cut a clip at the playhead: Edit > Blade.
- Add a title: Titles and Generators sidebar > Titles, then drag one above the clip.
- Add a transition: open the Transitions browser and drag one onto an edit point.
- Add an effect: open the Effects browser and drag one onto a clip. Adjust it in the Inspector.
- Colour correction: select the clip, then the Color tab of the Inspector.
- Speed: the Retime menu (a speedometer icon under the Viewer), or Modify > Retime.
- Separate sound from picture: Clip > Detach Audio.
- Change resolution or frame rate: select the project in the Browser, then Inspector > Modify.
- Reconnect missing files (red clips): File > Relink Files.
- Export a video file: the Share button, or File > Share.

## Gotchas
- The timeline is magnetic: deleting or moving a clip closes the gap and shifts everything after it. Use the Position tool, or Shift+Delete to leave a gap.
- Connected clips move with the clip they are attached to in the primary storyline.
- With automatic settings, the first clip added sets a project's resolution and frame rate.
- Rendering and saving happen in the background. There is no Save command.

## Shortcuts
- Play and pause: Space. Play backward, pause, forward: J, K, L.
- Tools: A Select, B Blade, T Trim, P Position, R Range.
- Edits: E append, W insert, Q connect, D overwrite.
- Blade at the playhead: Cmd+B. Default transition: Cmd+T. Retime: Cmd+R.
- Marker: M. Snapping: N. Skimming: S.
- Fit the timeline in view: Shift+Z. Export: Cmd+E.
