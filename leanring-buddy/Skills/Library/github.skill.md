## Layout
- Top bar: the menu (three lines) and logo at the left, the search box (press / to focus), then +, Issues, Pull requests, Notifications, and your profile picture, which opens the account menu.
- A repository has tabs under its name: Code, Issues, Pull requests, Actions, Projects, Wiki, Security, Insights, Settings. Settings shows only if you have admin rights.
- On the Code tab: the branch menu at the top left of the file list, Go to file, Add file, and the green Code button. The About box, Releases and Packages are on the right.
- A pull request has its own tabs: Conversation, Commits, Checks, Files changed.

## Where things are
- Clone address or ZIP download: the green Code button.
- New repository: + in the top bar > New repository.
- Fork, Star, Watch: buttons at the top right of the repository.
- New branch: branch menu > type a name > Create branch.
- Open a pull request: Pull requests > New pull request, or the Compare & pull request banner after a push.
- Review a pull request: Files changed > Review changes.
- Merge: the box at the bottom of the Conversation tab. The arrow on the button picks merge, squash or rebase.
- Edit a file in the browser: open it > the pencil icon.
- A file's history or blame: open it > History or Blame.
- Add collaborators: repository Settings > Collaborators.
- Protect a branch: repository Settings > Branches, or Rules > Rulesets.
- Secrets for Actions: repository Settings > Secrets and variables > Actions.
- Rename, change visibility, transfer, delete: repository Settings > General, Danger Zone at the bottom.
- SSH keys and access tokens: profile picture > Settings > SSH and GPG keys, and Developer settings.

## Gotchas
- There are two Settings. The repository's is a tab on the repository; your account's is under your profile picture.
- A pull request cannot merge while required checks or reviews are pending; the merge box says what is missing.
- Saving an edit in the browser is a commit on the branch shown in the branch menu.
- A link to a file on a branch changes as the branch moves. Press y first to get a permanent link.

## Shortcuts

- Jump to a line: l. Permanent link: y. Blame: b.
- Go to Code, Issues, Pull requests: g then c, g then i, g then p.
- List of shortcuts for the page you are on: ?.
