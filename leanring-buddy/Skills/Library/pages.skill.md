## Layout
- Toolbar: View, Zoom, Add Page, then Insert, Table, Chart, Text, Shape, Media, Comment, then Collaborate or Share, and at the right Format and Document.
- Format opens a sidebar for whatever is selected. For text it has three tabs: Style, Layout, More.
- Document opens a sidebar with Document, Section and Bookmarks tabs.
- View > Show Page Thumbnails adds a page list on the left.

## Where things are
- Paper size, orientation and margins: Document > Document tab.
- Headers, footers and page numbering for a section: Document > Section tab. Insert a number with Insert > Page Number.
- Fonts, paragraph styles, alignment, line spacing, bullets: Format > Style.
- Columns, indents and tabs: Format > Layout.
- Table of contents: Insert > Table of Contents.
- Footnote: Insert > Footnote. Page break: Insert > Page Break.
- Word count: View > Show Word Count.
- Track changes: Edit > Track Changes.
- Find and replace: Edit > Find > Find (Cmd+F), then the menu at the left of the search box.
- Export to Word, PDF, EPUB or plain text: File > Export To.
- Start new documents from a set template: Pages > Settings > General > For New Documents.
- Wrap text around a picture: select it, then Format > Arrange > Text Wrap.

## Gotchas
- There are two kinds of document. Word-processing documents flow text from page to page; page-layout documents are free-form pages of boxes. Switch with File > Convert to Page Layout or Convert to Word Processing.
- Changing text that uses a paragraph style puts an Update button beside the style name. Click it to change every paragraph in that style.
- A picture set to Stay on Page will not move with the text. Change it in Format > Arrange > Object Placement.
- Different headers on different pages need a new section: Insert > Section Break.
- Word files open fine, but saving goes to a .pages file unless you use Export To.

## Shortcuts
- Bold, italic, underline: Cmd+B, Cmd+I, Cmd+U.
- Comment: Shift+Cmd+K. Word count: Shift+Cmd+W.
- Bigger and smaller text: Cmd+Plus and Cmd+Minus.
- Copy style: Option+Cmd+C. Paste style: Option+Cmd+V.
- Show invisibles: Shift+Cmd+I.
