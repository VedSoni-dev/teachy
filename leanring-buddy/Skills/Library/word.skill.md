## Layout
- Title bar: AutoSave, the Quick Access Toolbar (save, undo, redo) and a search box.
- The ribbon, with tabs: Home, Insert, Draw, Design, Layout, References, Mailings, Review, View. Extra tabs appear for a selected picture, table, or header (Picture Format, Table Design, Header & Footer).
- The page in the middle. View > Sidebar > Navigation adds a list of headings and page thumbnails on the left.
- Status bar at the bottom: page number and word count at the left; view buttons and the zoom slider at the right.
- The Mac menu bar at the top of the screen (File, Edit, View, Insert, Format, Tools, Table, Window, Help) holds some commands that are not on the ribbon.

## Where things are
- Headings and text styles: the Styles gallery on Home.
- Font, size, bullets, alignment, line spacing: Home.
- Margins, orientation, paper size, columns: Layout.
- Page and section breaks: Layout > Breaks.
- Page numbers, headers, footers: Insert > Page Number, Insert > Header, Insert > Footer.
- Table of contents: References > Table of Contents.
- Footnotes and citations: References.
- Track changes and comments: Review > Track Changes, Review > New Comment.
- Spelling and grammar: Review > Editor.
- Word count: click the count in the status bar, or Tools > Word Count.
- Find and replace: Edit > Find > Replace.
- Show paragraph marks and breaks: the pilcrow button on Home.
- Save as PDF: File > Save As > File Format > PDF.
- Change the default font: Format > Font, choose it, then Default.
- Stop automatic corrections: Tools > AutoCorrect Options.

## Gotchas
- Odd formatting usually comes from the style applied to the paragraph. Change the style rather than each paragraph.
- Different headers, footers or page numbering in part of a document need a section break, then turning off Link to Previous on the Header & Footer tab.
- A blank page at the end is often an empty paragraph or a break. Show paragraph marks to find and delete it.
- A picture that will not move freely is set In Line with Text. Change it with Picture Format > Wrap Text.
- AutoSave works only for files stored in OneDrive or SharePoint.
- Track Changes stays on until switched off, and the marks travel with the file. Accept or reject them on Review before sending.

## Shortcuts
- Bold, italic, underline: Cmd+B, Cmd+I, Cmd+U.
- Find: Cmd+F. Replace: Ctrl+H. Insert a link: Cmd+K.
- Page break: Cmd+Return. Show paragraph marks: Cmd+8.
- Heading 1, 2, 3: Option+Cmd+1, 2, 3.
- Centre, left, right: Cmd+E, Cmd+L, Cmd+R.
- Paste and match the surrounding text: Option+Shift+Cmd+V.
