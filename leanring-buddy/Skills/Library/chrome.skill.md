## Layout
- Tab strip at the very top. Under it the toolbar: Back, Forward, Reload, the address bar (omnibox), then the Extensions puzzle icon, the profile picture, and the three-dot menu at the far right.
- The bookmarks bar sits under the toolbar when shown (Shift+Cmd+B).
- At the left end of the address bar is a small site-controls icon that opens permissions and cookies for the current site.
- On a Mac, the menu bar at the top of the screen (Chrome, File, Edit, View, History, Bookmarks, Profiles, Tab, Window, Help) repeats most of the three-dot menu.

## Where things are
- Settings: three-dot menu > Settings (Cmd+Comma).
- Clear history, cookies, cache: three-dot menu > Delete browsing data (Shift+Cmd+Delete). Older versions call it Clear browsing data.
- Incognito window: Shift+Cmd+N.
- Extensions: puzzle icon > Manage Extensions, or type chrome://extensions.
- Developer Tools: View > Developer > Developer Tools (Option+Cmd+I).
- Downloads: Shift+Cmd+J. History: Cmd+Y.
- Site permissions (camera, microphone, notifications): site-controls icon in the address bar > Site settings.
- Saved passwords: three-dot menu > Passwords and autofill > Google Password Manager.
- Default search engine: Settings > Search engine.
- Switch or add a profile: the profile picture in the toolbar.
- Update Chrome: three-dot menu > Help > About Google Chrome.
- Tab groups: Control-click a tab > Add tab to new group.

## Gotchas
- Each profile has its own bookmarks, extensions and sign-ins. If something is "missing", check which profile picture is showing.
- An extension can be installed but hidden. Open the puzzle icon and pin it to show its button.
- A pending update shows as a coloured Relaunch or Update button where the three-dot menu is.
- Incognito does not load most extensions unless allowed in each extension's details.

## Shortcuts
- Address bar: Cmd+L. New tab: Cmd+T. Reopen closed tab: Shift+Cmd+T.
- Hard reload: Shift+Cmd+R. Find: Cmd+F.
- Jump to tab 1 to 8: Cmd+1 to Cmd+8. Last tab: Cmd+9.
- Search open tabs: Shift+Cmd+A.
