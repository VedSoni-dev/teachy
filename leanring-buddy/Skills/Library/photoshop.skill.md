## Layout
- Tools panel down the left edge. A small triangle in a tool's corner means more tools are hidden under it: click and hold to see them.
- Options bar across the top, under the menus. It changes with the chosen tool (brush size, tolerance, font).
- Panels on the right: Layers at the bottom, with Properties, Adjustments, Color and Libraries above. Any panel can be opened from the Window menu.
- The Contextual Task Bar floats near the selection with the most likely next steps (Select subject, Remove background, Generative Fill). Show or hide it with Window > Contextual Task Bar.

## Where things are
- Resize the image: Image > Image Size. Add space around it: Image > Canvas Size.
- Crop: the Crop tool (C), then Return.
- Brightness, colour, levels, curves without damaging pixels: Layer > New Adjustment Layer, or the Adjustments panel.
- Remove a background: Properties panel > Quick Actions > Remove Background, or the Contextual Task Bar.
- Select the main subject: Select > Subject.
- Fill or replace an area with AI: make a selection, then Generative Fill on the Contextual Task Bar (Edit > Generative Fill).
- Remove an object the older way: Edit > Content-Aware Fill.
- Hide part of a layer: the mask button (a rectangle with a circle) at the bottom of the Layers panel.
- Save a JPEG or PNG: File > Export > Export As, or File > Save a Copy.
- Put the panels back: Window > Workspace > Reset Essentials.
- Settings: Photoshop > Settings (called Preferences before 2023).

## Gotchas
- Edits apply to the layer highlighted in the Layers panel. Most "nothing happens" problems are the wrong layer, a locked layer, or a hidden one.
- The Background layer is locked. Click its padlock to turn it into a normal layer.
- While a selection is active (moving dashed line), painting and edits only work inside it. Deselect with Cmd+D.
- Save As offers only a few formats for a layered file. Use Save a Copy or Export As for JPEG and PNG.
- A tool that behaves oddly: Control-click its icon at the left of the Options bar > Reset Tool.

## Shortcuts
- Undo: Cmd+Z (repeat for more steps). Free Transform: Cmd+T. Duplicate layer: Cmd+J.
- New layer: Shift+Cmd+N. Deselect: Cmd+D. Invert selection: Shift+Cmd+I.
- Brush smaller and larger: [ and ]. Default colours: D. Swap them: X.
- Zoom: Cmd+Plus and Cmd+Minus. Fit on screen: Cmd+0. Pan: hold Space.
- Levels: Cmd+L. Curves: Cmd+M. Hue/Saturation: Cmd+U.
