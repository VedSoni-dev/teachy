## Layout
- Sidebar on the left: Favorites (AirDrop, Recents, Applications, Desktop, Documents, Downloads), iCloud, Locations (disks, servers), Tags.
- Toolbar across the top: Back and Forward, the view switcher (Icons, List, Columns, Gallery), Group, Share, Tags, the Action menu (a circle with three dots), and Search at the far right.
- Optional bars at the bottom of the window: View > Show Path Bar and View > Show Status Bar. View > Show Preview adds a preview pane on the right.

## Where things are
- New folder: File > New Folder (Shift+Cmd+N).
- Rename: select the item and press Return.
- Show hidden files: Shift+Cmd+Period.
- Jump to a path: Go > Go to Folder (Shift+Cmd+G).
- File details and permissions: File > Get Info (Cmd+I).
- Zip: Control-click the item > Compress.
- Move instead of copy: Cmd+C, then Option+Cmd+V in the destination.
- Show file extensions: Finder > Settings > Advanced > Show all filename extensions.
- Choose what the sidebar lists: Finder > Settings > Sidebar.
- Connect to a server or NAS: Go > Connect to Server (Cmd+K).
- The user Library folder: hold Option and open the Go menu.
- Empty the Trash: Finder > Empty Trash (Shift+Cmd+Delete).

## Gotchas
- Return renames, it does not open. Open with Cmd+O or Cmd+Down Arrow.
- There is no Cut for files. Copy, then use Option+Cmd+V to move.
- Dragging between two disks copies; dragging within one disk moves. Hold Cmd while dragging to force a move.
- Finder > Settings was called Preferences before macOS 13.
- An item in the sidebar is only a shortcut. Dragging it out removes the shortcut, not the folder.

## Shortcuts
- Quick Look: Space. Move to Trash: Cmd+Delete. Duplicate: Cmd+D.
- New window: Cmd+N. New tab: Cmd+T. Find: Cmd+F.
- Views: Cmd+1 Icons, Cmd+2 List, Cmd+3 Columns, Cmd+4 Gallery.
- Up one folder: Cmd+Up Arrow. Back: Cmd+[.
- Jump to Applications: Shift+Cmd+A. Downloads: Option+Cmd+L. Home: Shift+Cmd+H.
