## Layout
- Top left: the document title, with the star, move-to-folder and save status beside it.
- Under the title, the menu bar: File, Edit, View, Insert, Format, Tools, Extensions, Help.
- Under that, the toolbar: undo, redo, print, spell check, paint format, zoom, the text style menu (Normal text, Heading 1), font, size, bold, italic, underline, text colour, highlight, link, comment, image, alignment, line spacing, lists, indent, clear formatting.
- At the right end of the toolbar: the mode menu (Editing, Suggesting, Viewing).
- Top right: version history (clock), comments, the Share button, your account.
- Left edge: the tabs and outline panel, built from the headings.

## Where things are
- Share or change who can view or edit: Share at the top right.
- Suggest edits instead of changing text: mode menu > Suggesting.
- See or restore an earlier version: File > Version history > See version history.
- Download as Word or PDF: File > Download.
- Margins, orientation, page colour, or switch to Pageless: File > Page setup.
- Headings: the text style menu in the toolbar.
- Table of contents: Insert > Table of contents.
- Page numbers, headers and footers: Insert > Page numbers, Insert > Headers & footers.
- Word count: Tools > Word count.
- Dictate: Tools > Voice typing (Chrome and some other browsers only).
- Columns and line spacing: Format > Columns, Format > Line & paragraph spacing.
- Copy the whole document: File > Make a copy.
- Work offline: File > Make available offline (Chrome or Edge).
- Find any menu command by name: Help > Search the menus.

## Gotchas
- There is no Save. Changes save as you type; the status next to the title says so.
- If the menus and toolbar are greyed out, you have view or comment access only. Ask the owner, or use Request edit access.
- Pageless mode removes page breaks, headers, footers and page numbers.
- A plain paste keeps the source formatting. Use Shift+Cmd+V to paste without it.
- The browser may take some shortcuts first. Help > Keyboard shortcuts lists the ones that work here.

## Shortcuts
- Link: Cmd+K. Comment: Option+Cmd+M. Find and replace: Shift+Cmd+H.
- Heading 1 to 6: Option+Cmd+1 to Option+Cmd+6. Normal text: Option+Cmd+0.
- Numbered list: Shift+Cmd+7. Bulleted list: Shift+Cmd+8.
- Clear formatting: Cmd+Backslash. Word count: Shift+Cmd+C.
- Search the menus: Option+Slash. All shortcuts: Cmd+Slash.
