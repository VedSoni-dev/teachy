## Layout
- Three columns: the folder list (iCloud, On My Mac, Shared, Smart Folders, Tags at the bottom), the list of notes, and the open note.
- Toolbar: the List or Gallery view switch, Delete, New Note, the Format (Aa) menu, Checklist, Table, Media, Link, Lock, Share, and Search at the right.
- View > Show Folders (Option+Cmd+S) brings back the folder list if it is hidden.

## Where things are
- New note: Cmd+N. New folder: Shift+Cmd+N.
- Title, Heading, Subheading, Body, lists: the Aa button or the Format menu.
- Checklist: Shift+Cmd+L. Table: Option+Cmd+T.
- Pin a note to the top: File > Pin Note.
- Lock a note: File > Lock Note. Set the password in Notes > Settings.
- Share or collaborate: the Share button in the toolbar.
- Tags: type # followed by a word in the note.
- Scan a document or take a photo with an iPhone: File > Insert from iPhone or iPad.
- All photos, scans and files across notes: View > Show Attachments Browser.
- Export: File > Export as PDF.
- Recover a deleted note: the Recently Deleted folder, for about 30 days.
- Default account and sort order: Notes > Settings.

## Gotchas
- Notes kept in a Gmail or other IMAP account cannot have checklists, tables, tags or locks. Use iCloud or On My Mac.
- On My Mac only appears after Notes > Settings > Enable the On My Mac account is ticked. Those notes do not sync.
- The first line of a note is its title in the list.
- A locked note still shows its title. Do not put secrets in the first line.
- Quick Note opens from the bottom-right hot corner or Fn+Q, and saves into the Quick Notes folder.

## Shortcuts
- Search all notes: Option+Cmd+F. Find in this note: Cmd+F.
- Title: Shift+Cmd+T. Heading: Shift+Cmd+H. Body: Shift+Cmd+B.
- Add a link: Cmd+K. Indent a list item: Tab.
- Bold: Cmd+B. Mark a checklist item done: Shift+Cmd+U.
