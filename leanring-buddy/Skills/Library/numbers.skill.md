## Layout
- Sheet tabs run along the top, with + at the left to add a sheet.
- A sheet is a blank canvas that holds one or more tables, charts and text boxes. A table is not the whole sheet.
- Toolbar: View, Zoom, Add Category, Pivot Table, then Insert, Table, Chart, Text, Shape, Media, Comment, then Collaborate or Share, and at the right Format and Organize.
- Format opens a sidebar with Table, Cell, Text and Arrange tabs. Organize opens Categories, Sort and Filter.
- Click a table to see its bars: letters across the top, numbers down the side, and round handles at the corners for adding rows and columns.

## Where things are
- Start a formula: click a cell and type =. The function browser opens on the right.
- Quick sum or average: Insert > Formula.
- Currency, percent, date, duration: Format > Cell > Data Format.
- Header rows and freezing them: Table > Header Rows, and Table > Freeze Header Rows.
- Sort and filter: Organize > Sort, Organize > Filter.
- Chart: select the cells, then Chart in the toolbar.
- Colour cells by rule: Format > Cell > Conditional Highlighting.
- Merge cells: Table > Merge Cells.
- Wrap long text: Format > Text > Wrap text in cell.
- Pivot table: select the table, then Pivot Table in the toolbar (Numbers 11.2 and later).
- Fill a series down or across: drag the yellow dot on the edge of the selected cell.
- Export to Excel, CSV or PDF: File > Export To.

## Gotchas
- CSV export writes one file per table, so a sheet with three tables gives three files.
- Cells are named by table: a formula pointing at another table reads like Table 2::B4.
- Typing past the last column does not add one. Use the round handle at the top right of the table.
- Excel files open fine, but saving goes to a .numbers file unless you use Export To.
- Header rows are left out of sums on purpose. Data typed into a header row will not be counted.

## Shortcuts
- Open the formula editor: type = in a cell.
- Add a row below: Option+Down Arrow. Add a row above: Option+Up Arrow.
- Add a column to the right: Option+Right Arrow. To the left: Option+Left Arrow.
- Stop editing and keep the cell selected: Cmd+Return.
- Find: Cmd+F. Comment: Shift+Cmd+K.
