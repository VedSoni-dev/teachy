Skills Library

A skill teaches Teachy its way around one app or site: where things are, what trips people up, the shortcuts worth knowing. Add one and Teachy uses it whenever you're in that app, in its answers and in every agent it runs for you.

Publish a skill Get Teachy for Mac

“Add to Teachy” opens Teachy, which shows you the skill before adding it. Or download the file and use Teachy → Settings → Skills → Add from file.

publish a skill

Know an app well? Write down where things are, once, and everyone's Teachy gets better at it.

  1. Write a Markdown file like the one here. Use the names people see on screen. Keep it short: under about 2,500 characters is what fits in Teachy's prompt.
  2. Try it yourself first: Teachy → Settings → Skills → Add from file.
  3. Open a pull request that adds it as academy/skillmarket/skills/<id>.skill.md in VedSoni-dev/teachy. The guide has the details.
  4. Once it's merged, it shows up here and in everyone's Teachy.
